```
Impact: New technicians struggle with issues veterans solved easily
```

```
Problem: Different technicians diagnose same issue differently

```

```
Purpose: Find cases with similar symptoms
Academic Basis: Information Retrieval (proven, established)
```

```
Technology: Statistical counting
Purpose: "Battery failure occurred in 72% of similar cases"
```

## 🎓 THESIS/PROJECT DEFENSE

### **Expected Questions:**

**Q: "Is this really AI?"**
```
A: "Yes, it uses established AI techniques: Case-Based Reasoning,
TF-IDF similarity, and pattern mining. These are proven AI methods
used in information retrieval and recommendation systems."
```

**Q: "Can it diagnose faults automatically?"**
```
A: "No, and that's intentional. It searches historical cases and
shows what worked before. The technician makes the final diagnosis
based on their expertise plus the system's suggestions."
```

**Q: "What if there's no similar case?"**
```
A: "The system honestly reports 'no similar cases found' and the
technician proceeds with normal troubleshooting. As more repairs
are recorded, coverage improves naturally."
```

**Q: "How accurate are the predictions?"**
```
A: "We don't call them predictions - we call them 'historical
patterns.' The system shows 'Battery failure occurred in 72% of
similar cases' - that's a fact, not a prediction. The technician
decides if it applies to the current case."
```

**Q: "Why not use deep learning?"**
```
A: "Deep learning requires thousands of labeled examples and
provides no explainability. Our approach works with smaller
datasets, provides transparent reasoning, and is academically
sound for this domain."
```
